# .github

Standaardbestanden voor alle repo's van Online Actief.

| Bestand | Waarvoor |
|---|---|
| `profile/README.md` | tekst op github.com/Online-Actief |
| `CONTRIBUTING.md` | de werkwijze, geldt voor alle repo's |
| `PULL_REQUEST_TEMPLATE.md` | sjabloon voor elke pull request |
| `ISSUE_TEMPLATE/` | formulieren voor fouten en wensen |
| `SECURITY.md` | waar je een beveiligingsprobleem meldt |
| `SUPPORT.md` | waar je terechtkunt met vragen |
| `workflow-templates/` | de controles, toe te voegen via Actions > New workflow |
| `beheer/` | regels voor `main` en het script om ze in te stellen |

Een repo met een eigen versie van een van deze bestanden gebruikt die in plaats van deze.

Deze repo is openbaar, anders gebruikt GitHub de bestanden niet. Zet hier dus nooit iets in over klanten, servers of geheimen.

Een nieuwe repo begin je vanuit [repo-template](https://github.com/Online-Actief/repo-template).
